# GeoAnki Suite — 地理暗記学習プラットフォーム 🌐🗾📜

日本の市区町村（全1,741自治体）、律令制令制国（五畿七道68国）、世界の国名・首都名（全196ヶ国・地域）を、高精度ベクターポリゴン白地図と5大特訓モードを用いて直感的に暗記できる統合型シングルページWebアプリケーション（SPA）です。

GeoGuessrのマップ特定（自治体・旧国・国特定）や、中学・高校・大学受験、公務員試験対策、大人の教養学習に最適化されています。

🌐 **公開URL**: [https://64bitfloat.github.io/GeoAnki/](https://64bitfloat.github.io/GeoAnki/)

---

## 🌟 収録モジュール

### 1. 🗾 全国1,741市区町村暗記トレーナー
- **JIS規格完全準拠**: 総務省の全国地方公共団体コード（JIS X 0402）に基づく全1,741自治体（市・町・村・特別区）。
- **政令指定都市行政区結合**: 全国20政令市の全175行政区を親市単位に集約しつつ、地図上では「区境界（破線）」と「市境界（実線）」の2層描画を実現。
- **離島クイックジャンプ**: 東京島嶼部、長崎五島、鹿児島奄美、沖縄先島諸島などへのワンタップ移動。
- **4段階難易度**: Lv.1（主要都市） / Lv.2（市） / Lv.3（町） / Lv.4（村） / 全自治体 / ⚠️弱点復習。

### 2. 📜 全国令制国・旧国名暗記トレーナー
- **全国68国完全網羅**: 五畿七道（畿内・東海道・東山道・北陸道・山陰道・山陽道・南海道・西海道）の全68国を収録。地域選択の手間なく全国一括で即座に学習可能。
- **4段階難易度レベル設定**:
  - Lv.1: 主要国（15国）— 尾張、武蔵、山城、摂津など著名な国
  - Lv.2: 中堅国（21国）— 信濃、陸奥、越後、肥後など頻出国
  - Lv.3: 一般国（24国）— 若狭、志摩、美作、日向など標準国
  - Lv.4: 小国・難関（8国）— 飛騨、志摩、淡路、壱岐、対馬など小国・難関国
  - 全て（68国） / ⚠️弱点復習
- **歴史・現代地理連携**: 各旧国のふりがな、現代の都道府県対応、名所・特徴ヒントを収録。

### 3. 🌍 世界の国名・首都名暗記トレーナー（新規モジュール）
- **国連加盟国＋主要地域**: 全196ヶ国・地域（ISO 3166-1 alpha-3 準拠）。
- **双方向出題トグル**:
  - 「🗺️ 地図位置 → 国名を当てる」
  - 「🏛️ 国名 → 首都を当てる」
  - 「🏛️ 首都名 → 地図上の国を当てる」
- **国旗絵文字表示**: 各国の国旗アイコンを鮮明に表示。
- **地域・難易度分類**:
  - 地域: 全世界、アジア、ヨーロッパ、アフリカ、北アメリカ、南アメリカ、オセアニア
  - 難易度: Lv.1（主要国・G7） / Lv.2（一般国） / Lv.3（地域中堅国） / Lv.4（小島嶼国・難関国） / ⚠️弱点復習

## 🎯 5大特訓モード（全モジュール共通）

1. **🎯 場所当てモード (`locate`)**:
   - 地名（国名・首都・自治体・旧国）が提示され、該当するポリゴンを直接タップ。
   - **カメラ自動移動完全無効**: カメラが動いて答えの方向を教えてしまうのを完全防止。
   - **ホバー漏洩完全防止**: 出題中の正解箇所にカーソルを乗せても他と同色の通常ホバー色を維持。
   - **消去法排除**: 正解済みの地域も未正解地域と同色のダークトーンを維持。
2. **🔤 4択モード (`name`)**:
   - 出題対象ポリゴンがイエロー点滅し、画面中央へスムーズに自動センタリング（maxZoom最適化）。
   - 同一地域・同一難易度からダミー選択肢を抽出。
   - PCキーボード `[1]` `[2]` `[3]` `[4]` キー対応。
3. **✍️ 記入モード (`type`)**:
   - 点滅ポリゴンの名称を入力。表記揺れ吸収辞書（漢字・カタカナ・ひらがな・英語・通称）を内蔵。
   - **Enterキー完結型連続演習**: 入力 → Enterで回答判定 → もう一度Enterで即座に次問へ進行。
4. **🔍 探索モード (`explore`)**:
   - 地図上のポリゴンを自由にタップして予習・閲覧できるフリーモード。
   - 「この地域をテスト 🎯」ボタンから即座に個別テスト突入。
5. **⚠️ 弱点復習モード (`weak`)**:
   - 直近で間違えた問題のみを自動抽出し、通常学習と全く同一の難易度グレーアウト環境で再演習。

## 🛠️ パフォーマンス & システム設計

- **100dvh 全画面フィット**: スマホのアドレスバー伸縮やスクロールバウンスを完全排除。
- **Leaflet SVG 余白バッファ（`padding: 1.5`）**: 地図の素早いパン・ズーム操作時にも画面外ポリゴンが欠落しないプリレンダリング。
- **GPU ハードウェアアクセラレーション**: `.leaflet-pane > svg` への `translate3d(0, 0, 0)` 適用。
- **Web Audio API 内蔵シンセサイザー**: 外部音声ファイル不要のゼロレイテンシ波形合成チャイム。
- **LocalStorage 分離管理**:
  - `geoanki_muni_v1`（市区町村）
  - `geoanki_province_v1`（旧国名）
  - `geoanki_world_v1`（世界の国名・首都）
  - 個別リセット・一括バックアップ（JSONエクスポート／インポート）対応。

## 🚀 ビルド & デプロイ方法

```bash
# 世界の国マスターデータおよびGeoJSONの再生成（必要な場合）
python prepare_world_data.py

# index.html のビルド
python build_app.py
```

生成された `index.html` 単体でブラウザからそのまま開いて完全スタンドアロンで動作します。
